# `whoami` — Carlos Cabrera

> Interactive, cyber-themed résumé for **Carlos Cabrera** — Information Security Specialist & Cyber Incident Responder.

A self-contained, dependency-free single-page résumé. Plain HTML/CSS/vanilla-JS — no build step, no
framework, no tracking. Dark "security console" theme with scroll reveals, animated stats, and a
print-to-PDF stylesheet.

## 🔗 Live

Live at **https://resume.cabrerapr.com/** (GitHub Pages + custom domain).

## Run locally

```bash
# any static server works — e.g.
python3 -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` directly in a browser (no server required — everything is inline).

## What's inside

| File | Purpose |
|------|---------|
| `index.html` | The résumé content (summary, skills, experience, education, certs, contact) |
| `styles.css` | Dark theme, responsive layout, animations, print styles |
| `app.js` | Scroll-reveal, count-up stats, rotating job title — vanilla JS, no deps |

background, and buttons for a clean one-pager.
